# website-to-api verification map

Agent is the user. Prove capture → distill → replay before claiming a site is cheap.

## Baseline

- Success state of the UI path is defined in one line.
- HAR exported only after that state is visible.
- Recipe has no cookie/token values.
- Replay uses live session auth.
